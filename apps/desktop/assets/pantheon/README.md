# Pantheon desktop assets

Pantheon-branded icons (`icon.ico`, `icon.png`, `icon.icns`) are not yet produced.

The packaged app currently ships the upstream `assets/icon.*` files. Replacing them is a follow-up release task and requires updating `build.icon` and the `extraResources` `icon.ico` entry in `package.json`.

No upstream trademarks may ship in the final release installer.
